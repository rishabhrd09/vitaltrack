Glossary

ASGI
The asynchronous interface between a Python web server (Uvicorn) and an application (FastAPI).
Access token
A short-lived signed JWT sent on every request as Authorization: Bearer ….
Refresh token
A longer-lived signed JWT used once to obtain a new token pair; its jti has a database row so it can be revoked.
Optimistic concurrency
Writers do not lock while reading; each write states the version it read and fails if the row changed.
Idempotency key
A client-generated id (localId) that makes repeating the same request safe.
Partial unique index
A unique index that only covers rows matching a condition.
Advisory lock
A PostgreSQL lock on an application-chosen number; here held until the transaction ends.
Liveness vs readiness
Liveness: the process answers (/live). Readiness: it can do useful work, including reaching the database (/health).
Migration
A versioned schema change applied by Alembic in order.
EAS profile
A named build configuration in eas.json that fixes the API address and package type.
TanStack Query
A client library that caches server data, refetches it and invalidates it after writes.
SecureStore
Expo's encrypted key-value storage (Android Keystore; iOS Keychain).
Argon2id
A memory-hard password-hashing function (RFC 9106).
HS256
HMAC with SHA-256: a shared-secret signature for JWTs.
Fernet
Authenticated symmetric encryption (AES-128-CBC with an HMAC-SHA256 tag) from the cryptography library.
BOLA
Broken object-level authorization: reading or changing another user's object by its id.
