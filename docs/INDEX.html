Evidence rules

  • Source files establish what the code does and what configuration intends.
  • Tests establish the scenarios they actually run — no more. A mocked provider test does not verify real Groq; an autolinking check does not verify a compiled AAB.
  • Provider dashboards, deployed artifacts and restore drills establish live operations. A green CI summary, a healthy /health or a deploy-hook 200 do not prove which commit is running.
  • A historical "VERIFIED" label means verified on that date, not today. A planning example is not an implemented feature.
