CareKosh uses the C API directly, without the Python wrapper, cloud tools,
telemetry wrapper or automatic runtime/model downloader. Runtime code is linked
at build time only. Model data is downloaded only after an explicit user action.
Both NEEDLE_TELEMETRY=0 and DO_NOT_TRACK=1 are set before loading the runtime.
The initial diagnostic adapter forces English and consumes completed recordings.

The JNI library links a private static LLVM C++ runtime. LLVM-NDK-NOTICE.txt
is the complete toolchain notice from the Android NDK 27.1.12297006 used for
verification, including Apache-2.0 WITH LLVM-exception and included notices.
ANDROID-NDK-SYSROOT-NOTICE.txt contains the matching NDK sysroot notices.
No C++ objects or exceptions cross this library's JNI C boundary.
